Library

drag prop = move (snap 6 in, shift = free; its controllers follow a whole block) · drag controller box = move it · drag empty = select box · shift-click = add to selection · wheel = zoom · hold H (or ✋) + drag = pan · double-click = paint

Selection

click toggles · drag = lasso · shift+click = flood one feature · W then two clicks = wire range · 1–9 = move selection into region N

Regions

Click another prop in the group list on the left to paint it; changes save automatically and the preview picks them up at once.
Pixels in no region are the implicit region rest. The Incandescent pack draws each region in its painted colour.

Cards

One SD card per controller. Every card gets the identical frame count; empty ports are 32-px stubs. Files are Sc-01-01.rgb in out/studio/cards/<controller>/. Reformat a card before every big copy (a fragmented card made controller B drift on the bench).
Placement PDF (one page per group)

One scene per song

Cuts the show at the tempo map's song boundaries and renders one scene file per song (Sc-NN-01.rgb from the first scene number up). The runner selects the next scene over DMX at each boundary, which restarts every controller from frame 0 together — a free re-sync per song — and no card file is longer than one song. out/studio/cards/cues.json lists scene, DMX value and times for the runner.

AI final pass

Export a readable digest of the whole show plus project.json, give both to Claude ("here is my show, tighten the transitions / vary the Snowflakes / fix song 5…"), then import the project.json it returns. The import validates every clip (unknown effects and out-of-range values are fixed or dropped, with a report) and keeps a backup of the previous project.
